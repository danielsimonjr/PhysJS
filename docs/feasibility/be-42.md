# BE-42 is not a derivation-step

The catalog equation is the Hawking temperature

```
T_H = ℏ c³ / (8 π G M k_B)
```

with the horizon writing `T_H = ℏ c / (4 π k_B r_s)` at `r_s = 2 G M / c²`. The composition edges are `be-42` (mass to `T_H`) and `be-42-via-rs` (`r_s` to `T_H`). This note does not change `PhysJS.HawkingUnruh.dictionary` and does not add a theorem. A definitional copy of the formula would not be that equation.

## Already proved

`PhysJS.HawkingUnruh.dictionary` is the manifest theorem for `be-42`. For `c, G, M, k_B ≠ 0`,

```
T_H(2 G M / c²) = T_H(M)
T_U(c⁴ / (4 G M)) = T_H(M)
```

where `T_H(M) = ℏ c³ / (8 π G M k_B)`, `T_H(r) = ℏ c / (4 π k_B r)`, and `T_U(a) = ℏ a / (2 π c k_B)`. `T_U(c⁴ / (2 G M))` is not `T_H(M)`. `#print axioms` reports `propext`, `Classical.choice`, and `Quot.sound`. The covers line calls this a cross-check of the `8π`, `4π`, and `2π` dictionary. It names BE-57 and `be-42-via-rs`. It is not the Hawking effect.

## What blocks the catalog equation

Hawking's 1975 result is a temperature of a quantum field on the Schwarzschild background. The coefficient is fixed by two steps that are not in the library:

1. Schwarzschild surface gravity `κ = c⁴ / (4 G M)`.
2. `T = ℏ κ / (2 π k_B c)`, from the KMS condition on that background (Bogoliubov transformation, or the Euclidean period `2π`).

PhysLean at `af484f78ee0701290595f8bf892b157b10d64940` has Lorentz boosts and FLRW. It has no Schwarzschild metric, no surface gravity, no Rindler wedge, and no Bisognano–Wichmann theorem. UPT records the same gap for BE-57: repeating the definition of `T_U` adds nothing, and the wedge theorem is the missing piece. BE-57 has no reference of its own. The BE-42 cross-check is that algebra, and it stops there on purpose.

`hawking = ℏ c³ / (8 π G M k_B)` is the definition of `hawking`. Reflexivity would not derive `1/(8π)`. UPT's chain pipeline admits a catalog id as a seed only when the theorem states the catalogued equation (`CATALOG_EQUATION_KEYS` in `src/atlas/physjs-ref.ts`). That set is `be-12`, `be-16`, `be-21`, `be-27`, `be-33`, `be-37`, `be-40`, `be-43`, `be-50`, `be-54`, `be-55`, `be-59`, `be-60`, and `be-63`. `be-42` is not in it. The stored reference is kind `cross-check` on `PhysJS.HawkingUnruh.dictionary`. Putting a definitional equality in that set would compose an underived coefficient. This note does not do that.

## Units-only partial, not taken

With the usual dimensions of `ℏ`, `c`, `G`, `M`, and `k_B`, Buckingham-Pi gives

```
T = C ℏ c³ / (G M k_B)
```

`C` is dimensionless and unfixed. `C = 1/(8π)` is not a conclusion. `PhysJS.Dimensional.monomial_form` states that shape and leaves both the constant `f(1,…,1)` and the exponent vector as hypotheses. The BE-57 spec already says the analogous monomial `T = C ℏ a / (c k_B)` is not a derivation-step, because units do not set `C = 1/(2π)`. The same refusal applies here.

## Derivation-step partial, not taken

Assume `κ = c⁴ / (4 G M)` and `T = ℏ κ / (2 π c k_B)`. Then `T = ℏ c³ / (8 π G M k_B)`. That calculation is the second conjunct of `dictionary`, with `unruh` as the second premise. It does not discharge either premise. Discharging the second premise is BE-57, which is the wedge theorem above.

## Chains

In the composition graph these pairs already join, as symbolic substitutions:

- `be-42 >> be-27`
- `be-42 >> be-33`
- `be-42-via-rs >> be-12`

Pairs that end at `be-16` join the same way. The chain pipeline drops a cross-check: a cross-check is a fact about part of an entry, not a premise of a new equation. The join is not evidence that `8π` has been derived.
