# `@danielsimonjr/physjs`

This directory is the reserved place for a TypeScript engineering-physics package, on a packages layout like [MathTS](https://github.com/danielsimonjr/MathTS).

The proposal is [docs/design/library-architecture.md](../../docs/design/library-architecture.md). It is awaiting approval. This directory stays empty until a tier in that note is approved.

Nothing here is published. The Lean proofs in the repository root are a different artifact, and UPT reads them through `manifest/bridges.json`.

The handle `@danielsimonjr/physjs` was verified free on the registry on 2026-09-22. It is lowercase because npm rejects uppercase in a new package name.
