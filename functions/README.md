# @danielsimonjr/physjs

The public package of [PhysJS](https://github.com/danielsimonjr/PhysJS), a TypeScript physics engine built on MathTS. It creates 3D worlds (`createWorld`), adds and removes bodies (`addBody`, `removeBody`), applies forces and torques (`applyForce`, `applyTorque`) and steps them with semi-implicit Euler (`step`). Gravity, quaternion rotation and the other mathematics come from MathTS. See the [repository README](../README.md) for an example and docs/design/PHYSICS_ENGINE_PLAN.md for the milestones.
